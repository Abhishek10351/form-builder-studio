# Server

The server is the FastAPI API for authentication, forms, templates,
publishing, and submissions. It stores application data in MongoDB.

## API

- Authentication and users
- Form creation, listing, retrieval, and deletion
- Template-based form creation
- Publishing and unpublishing through the form editor
- Public form retrieval and submission
- Owner-only submission retrieval

The complete endpoint reference is generated by FastAPI:

- [OpenAPI UI](http://localhost:8000/docs)
- [ReDoc](http://localhost:8000/redoc)

## Stack

FastAPI · Python 3.12+ · MongoDB · Pydantic · JWT · `uv`

## Development

```bash
cd server
uv run fastapi dev app/main.py
```
